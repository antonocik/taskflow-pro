# TaskFlow Pro

Aplikasi manajemen tugas (to-do list) modern berbasis browser. Mendukung kategori, prioritas, tanggal jatuh tempo, filter, pencarian, dan penyimpanan otomatis di LocalStorage.

## Fitur
- Tambah, edit, hapus, dan tandai selesai tugas
- Kategori: Kerja, Pribadi, Belanja, Lainnya
- Prioritas: Tinggi, Sedang, Rendah
- Tanggal jatuh tempo dengan indikator terlambat
- Filter berdasarkan status, kategori, prioritas
- Pencarian cepat
- Statistik ringkas
- Penyimpanan LocalStorage (data tetap ada setelah refresh)
- Responsif untuk desktop dan mobile

## Menjalankan
Tidak memerlukan build step. Buka `index.html` di browser, atau jalankan server lokal:

```bash
python3 -m http.server 8080
```

Lalu buka http://localhost:8080
